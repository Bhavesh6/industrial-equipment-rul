Architecture

The RS-380 Motor Prognostics system acquires six-axis vibration (MPU-6050), temperature, and current telemetry from a physical motor rig. A FastAPI service ingests readings into SQLite, then feeds a Gradient Boosting + LSTM ensemble that outputs a continuous Health Index (0–100) and Remaining Useful Life estimate with 90% confidence bounds. SHAP attribution identifies the dominant degradation mode per reading. Alerts fire when health drops below configurable thresholds. This dashboard is served directly by Python's HTTP server and optionally embedded in Streamlit.
